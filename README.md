# Codyssey AI 올인원 - 미션 1: 개발 워크스테이션 구축

## 1. 실습 내용 요약
- Linux CLI(터미널) 기반 작업 디렉터리 구성 및 Git 버전 관리 초기화
- Dockerfile을 활용한 Nginx 웹 서버 이미지 빌드 및 컨테이너 실행
- 포트 매핑(-p 8080:80)을 통한 호스트-컨테이너 간 웹 접속 확인
- 바인드 마운트를 통한 로컬 소스 변경 즉시 반영 검증
- Docker Volume을 활용한 컨테이너 삭제 후 데이터 영속성 검증

## 2. 핵심 구조적 원칙 (왜 이런 설계가 필요한가?)
- **이미지와 컨테이너의 분리**: 실행 환경을 불변의 '이미지'로 패키징하고 실제 동작하는 '컨테이너'와 분리함으로써, 어느 환경에서든 동일한 실행 결과를 재현('내 컴퓨터에서만 작동하는 문제' 해결)할 수 있습니다.
- **격리된 실행 환경**: 호스트 OS와 독립된 공간에서 애플리케이션을 실행하여 프로그램 간 버전 충돌을 막고 안정성을 높입니다.
- **포트 매핑 연결 방식**: 기본적으로 외부와 차단된 컨테이너의 내부 포트(80)를 호스트 포트(8080)와 명시적으로 연결해, 보안을 유지하면서 외부 접속 통로를 제어합니다.
- **스토리지 분리 (바인드 마운트 & 볼륨)**: 컨테이너는 삭제 시 내부 데이터가 사라지는 일회성 특성을 가집니다. 개발 중 실시간 코드 반영에는 호스트 폴더를 연결하는 **바인드 마운트**를, 컨테이너가 삭제·재생성되어도 핵심 데이터를 영구 보존하려면 독립된 생명주기를 갖는 **볼륨(Volume)**을 분리해 연결해야 합니다.
